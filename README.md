# LLM-Toolbox

A personal collection of resources, study notes, and practical tips for working with LLMs and AI tools.

## What's here

- **Notes** — things learned about how LLMs work, prompting, tool use, agents, etc.
- **Resources** — links to papers, docs, courses, or tools worth remembering.
- **Tips** — short, practical tricks that made something work better (prompting patterns, workflow shortcuts, gotchas to avoid).

No fixed structure yet — folders will be added as content accumulates rather than planned upfront.

## Notes

- Keep entries short and dated where relevant.
- Favor "what I learned / what worked" over exhaustive reference material — link out to sources instead of copying them.
